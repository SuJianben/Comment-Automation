## 2026-11-03：Judge.me 接收后被误标失败

- 状态：已修复并验证。
- 复现条件：提交草稿后，Judge.me 返回 HTTP 201 及后台处理消息。
- 原因：控制器只将 HTTP 200 标记为已提交，把 201 误判成失败。
- 修复：将 HTTP 200 和 201 记录为已提交，其他非预期响应仍需核实；保留原始响应。
- 数据修正：核对第 109 条记录后，未再次发送请求，将本地误标失败修正为已提交；随后只读查询到商品、客户和内容匹配的 Judge.me 评论，接口返回 published=true，记录核实依据后标记 synced。
- 自检：20 项测试通过，覆盖 201 接收、非预期 2xx 和防重复提交；Judge.me 评论 ID 1404753742 已通过只读接口核验。
- 限制：未对店铺前台页面进行视觉核验；11 月 2 日表单未进入提交流程的问题与本问题并非同一现象。
